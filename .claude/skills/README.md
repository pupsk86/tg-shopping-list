# Project skills

Skills in this folder load for anyone running Claude Code in this repo. They are not installed user-wide.

## From Matt Pocock's skills

Copied from [mattpocock/skills](https://github.com/mattpocock/skills) at commit `49dd158d1076134a641b33efb035946536778336` (MIT, see `LICENSE-mattpocock-skills`). The Codex-only `agents/openai.yaml` files were left out. Update by hand: re-copy a skill folder from a newer commit and bump the commit above.

| Skill | Use it for |
| --- | --- |
| `ask-matt` | Router: which skill fits where you are |
| `grill-with-docs` | Design interview that records terms in `GLOSSARY.md` and decisions as ADRs |
| `grill-me` / `grilling` | The same interview without the docs (`grilling` is the primitive) |
| `domain-modeling` | Glossary and ADR discipline used by `grill-with-docs` |
| `setup-matt-pocock-skills` | One-time config: issue tracker, doc layout |
| `to-spec` | Turn a discussion into a spec |
| `to-tickets` | Split a spec into tracer-bullet tickets with blocking edges |
| `implement` | Build a ticket with `tdd`, then `code-review` |
| `tdd` | Red-green loop at agreed seams |
| `codebase-design` | Deep-module vocabulary for module shape |
| `code-review` | Two-axis review (standards + spec) |
| `prototype` | Throwaway code to answer a design or UI question |

Left out for now (can be added later): `triage`, `wayfinder`, `implement-spec`, `diagnosing-bugs`, `research`, `retro`, `improve-codebase-architecture`, `pr`, `wizard`, `handoff`, and the productivity extras.
